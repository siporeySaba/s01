# יצירת PDF לסיפור

יוצר קובץ PDF בפורמט הקבוע של סיפורי סבא: עמוד שער עם לוגו, כותרת, תקציר וטבלת "מאת / לגילאים",
ואחריו עמודי הסיפור עם לוגו קטן בראש כל עמוד ומספור עמודים.

```
node tools/story-pdf/make-pdf.mjs story.txt
```

הקובץ נשמר בתיקייה `pdf story`. צריך רק Node ודפדפן Edge (או Chrome), בלי התקנות נוספות.

## פורמט קובץ הסיפור
ראו `example-story.txt`:
- שורות פתיחה: `כותרת:`, `פרק:`, `תקציר:`, `גילאים:` (ברירת מחדל 3-12), `מאת:` (ברירת מחדל "חגי כהן, סיפורי סבא"), `קובץ:` (שם קובץ היעד).
- שורת `---` מפרידה בין הפרטים לסיפור.
- `## ` בתחילת שורה = כותרת משנה. כל שורה אחרת = פסקה. כוכביות נמחקות אוטומטית.

## חיבור ה-PDF לפרק באתר
מוסיפים שורה לקובץ `pdf story/links.json` עם שם הפרק (כמו ביוטיוב, בלי "סיפורי סבא |") ושם הקובץ.
הסנכרון האוטומטי מחבר את הקובץ לפרק בריצה הבאה. קובץ הטקסט המקורי נשמר ב-`pdf story/src`.
